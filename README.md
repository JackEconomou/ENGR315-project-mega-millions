# ENGR315-project-mega-million
Our project analyzes the Mega-Millions.csv file with winning mega million numbers, date the number was pulled, mega ball, and the multiplier associated with each winning number combination. We are here to figure out any correlations with the questions we want answers for using our knowledge and skills gained in our ENGR 315 class.

Project Title: Do the Mega Millions winning numbers have a suspicious correlation

Team Name: Millionaires
Contributors: Jack Economou, Bryce Jennings, and Dilan Guox

Objective and Motivation:
We are using the winning mega millions dataset from data.gov there is a .csv file that has a winning numbers, multiplier, date, and megaball columns for our analysis.
  Questions we are asking and solving
  1. Is there an even distribution between mega ball numbers drawn?
  2. Is there a significant difference in the average sum of the 5 main winning numbers between tuesday and friday drawings?
  3. What is the longest gap (measured in number of consecutive draws) that any individual Mega Ball number has gone without being drawn?

Implementation Details:
Question 1 will be answered using a chi-squared test
Question 2 will be answered using a two sample t-test
Question 3 will be answered by sorting and using indices.
